# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.1.0] - 2026-08-20
### Added
- Enterprise CI/CD pipelines via GitHub Actions.
- Docker and Kubernetes deployment targets.
- Local LLM fallback structure (`models/nlp`).
- Dynamic plugin system loading (`plugins/`).

## [2.0.0] - 2025-11-15
### Changed
- Complete rewrite of the NLP engine to support GPT-4-turbo.
- Re-architected audio streaming to achieve near-zero latency.

## [1.0.0] - 2024-01-10
### Added
- Initial public release of Aura Voice Assistant.
- Basic Windows automation (mouse/keyboard).
